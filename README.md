# Skryvo docs

The source of [skryvo.ai/docs](https://skryvo.ai/docs/): how Skryvo works, written from its code. Every page here
is the Markdown of one page on the site, at the same path (`channels/linkedin.md` is
[skryvo.ai/docs/channels/linkedin/](https://skryvo.ai/docs/channels/linkedin/); a section's `index.md` is its home).

## Suggest a change

Found something wrong, unclear or missing? Every page on the site has an **Edit this page** link that opens its file
here in GitHub's editor. Make the change and open a pull request; say what you saw in the product if the page
disagrees with it.

We check each change against the product, apply the ones we accept to the site, and the next sync brings the file
here up to date, so your pull request is closed with a note rather than merged. Small fixes (a typo, a broken step)
are as welcome as new sections.

For questions about using Skryvo, write to support@skryvo.ai.
