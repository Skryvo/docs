# API

> Sign-in, errors, limits, webhooks and every route of the REST API.

Sign-in, errors, limits, webhooks and every route of the REST API.

- [API overview and sign-in (`Overview and sign-in`)](https://skryvo.ai/docs/api/overview/): The REST API's address, its OpenAPI file, signing in with an API key or OAuth, and the first call.
- [API errors (`Errors`)](https://skryvo.ai/docs/api/errors/): What each HTTP error from the API means, with the body it carries and what to do about it.
- [API rate limits and plan limits (`Limits`)](https://skryvo.ai/docs/api/limits/): How many calls a key may make, the limits on a single call, and what each plan allows a month.
- [API reference (`Reference`)](https://skryvo.ai/docs/api/reference/): Every route of the REST API, grouped by what it works on, each linked to its full page.
- [Webhooks](https://skryvo.ai/docs/api/webhooks/): Get a signed POST when a post is published or fails, an article is ready, or results come in.
- [Calls that answer later](https://skryvo.ai/docs/api/answer-later/): Send a callback_url with a long call and get a 202 at once; the answer arrives signed at your address, or by polling the job.
