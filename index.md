# Skryvo docs

> How Skryvo works, written from its code.

How Skryvo works today, written from its code: the app, every channel, the AI agent tools, the REST API and the automations built on them. Every page has a Markdown copy at the same address ending in `.md`.

- [Start](https://skryvo.ai/docs/start/): What Skryvo is, a first post from sign-up to live, the words it uses and its plans.
- [Using Skryvo](https://skryvo.ai/docs/using/): Every part of the app, from a brand's voice to the results a post earns.
- [Channels](https://skryvo.ai/docs/channels/): What each channel takes, how to connect it, and why a post can fail.
- [AI agents](https://skryvo.ai/docs/agents/): Connect Claude, ChatGPT, Cursor or any MCP client, and what an agent may do.
- [Agent tools](https://skryvo.ai/docs/tools/): Every tool an agent can call, with its inputs, an example and its cost.
- [API](https://skryvo.ai/docs/api/): Sign-in, errors, limits, webhooks and every route of the REST API.
- [Automate](https://skryvo.ai/docs/automate/): Working recipes for n8n, Make, Zapier, Activepieces, GitHub Actions and cron.
- [Recipes](https://skryvo.ai/docs/recipes/): Whole jobs from start to finish, each built only from what Skryvo does today.
- [Trust](https://skryvo.ai/docs/trust/): Channel status, security, data, known limits and what changed.
