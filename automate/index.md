# Automate

> Working recipes for n8n, Make, Zapier, Activepieces, GitHub Actions and cron.

Working recipes for n8n, Make, Zapier, Activepieces, GitHub Actions and cron.

- [Skryvo in n8n (`n8n`)](https://skryvo.ai/docs/automate/n8n/): An n8n workflow that writes posts in a brand's voice, gets a yes and schedules them, over the REST API.
- [Skryvo in Make (`Make`)](https://skryvo.ai/docs/automate/make/): A Make scenario that writes posts in a brand's voice and schedules the approved ones, over the REST API.
- [Skryvo in Zapier (`Zapier`)](https://skryvo.ai/docs/automate/zapier/): A Zap that writes posts in a brand's voice from each new item and schedules them, over the REST API.
- [Skryvo in Activepieces (`Activepieces`)](https://skryvo.ai/docs/automate/activepieces/): An Activepieces flow that writes posts in a brand's voice and schedules them, over the REST API.
- [Skryvo in GitHub Actions (`GitHub Actions`)](https://skryvo.ai/docs/automate/github-actions/): A workflow that turns each published release into posts, then schedules them after a reviewer approves.
- [Cron and other CI (`Cron and CI`)](https://skryvo.ai/docs/automate/cron/): A shell script on a schedule that plans next week's posts and adds them to the calendar as planned topics.
