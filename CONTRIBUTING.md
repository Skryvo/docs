# Contributing

1. Open the page on [skryvo.ai/docs](https://skryvo.ai/docs/) and choose **Edit this page**, or edit the file here.
2. Keep to what the product does today; if you are describing a bug, open an issue instead.
3. Open a pull request with one change per request.

Pages are written in plain English for people from any field. Links between pages use full `https://skryvo.ai/docs/…`
addresses. We apply accepted changes on the site; the sync then overwrites the file here.
