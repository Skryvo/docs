# What changed

> Where every shipped change to Skryvo is recorded, and how the docs keep up with it.

## The changelog

The [changelog](https://skryvo.ai/changelog/) lists every change people can see in Skryvo, newest first, one line each, dated the day it reached production. A change that is still being built is not listed.

## How these docs keep up

The docs are written from Skryvo's code and its feature specifications, and each page says when it was last checked against the product. Lists that change, such as the channels, the agent tools, the API's routes and the plans, are drawn from the same data the rest of the site and the app use, so a new channel or tool appears here when it ships. The API reference is generated from the API's own [OpenAPI document](https://api.skryvo.ai/openapi.json).
